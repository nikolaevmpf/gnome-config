# gnome-config

Репозиторий с конфигурациями NixOS для GNOME-окружений на нескольких машинах.

## Назначение профилей

- `vm` — тестовая виртуальная машина KVM/QEMU.
- `nuc` — домашний компьютер для работы и серфинга.
- `02i0132` — рабочий компьютер для работы, серфинга и игр.
- `zet` — домашний игровой компьютер.
- `dell` — отдельный laptop-профиль.

## Структура

- `flake.nix` — точка входа и описание профилей NixOS.
- `modules/base/` — базовая система: сеть, звук, очистка, SSH, пользователь.
- `modules/desktop/` — GNOME, шрифты, терминал.
- `modules/home/` — подключение Home Manager.
- `modules/roles/` — роли машин: work, browsing, gaming, virtualization.
- `hosts/` — оборудование, диски и специфичные настройки каждого хоста.
- `home/` — пользовательские настройки Home Manager.
- `home/common/` — общие GNOME/Dock/Ghostty настройки.
- `home/hosts/` — отличия конкретных машин.

## Что изменено в этой версии

- Удалён AmneziaVPN из всех профилей.
- Удалён отдельный input `nixpkgs-unstable`, который был нужен для AmneziaVPN.
- Структура репозитория переработана по ролям.
- Home Manager настройки разделены на общие и хост-специфичные.
- Профили приведены к явному назначению:
  - `nuc` — работа и серфинг
  - `02i0132` — работа, серфинг и игры
  - `zet` — игры
  - `vm` — тестовая KVM-машина

## Применение

На уже настроенной машине:

```bash
nix flake lock
sudo nixos-rebuild build --flake .#<profile>
sudo nixos-rebuild switch --flake .#<profile>
```

Где `<profile>` — один из:
- `vm`
- `nuc`
- `02i0132`
- `zet`
- `dell`

## Примечания

- Все диски по возможности идентифицируются по UUID.
- Пользовательские приложения и настройки GNOME находятся в Home Manager.
- Системные вещи вроде Steam, GameMode, libvirt и Flatpak остаются в NixOS.
